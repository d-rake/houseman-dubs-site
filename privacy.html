HOUSEMAN DUBS / PROJECT INFORMATION

Privacy policy

Effective date: 2026-10-18 · Contact: drake.mooneyham@gmail.com

Who we are

Houseman Dubs is the animated alter-ego of music producer drake mooneyham. "Houseman Dubs Scheduler" (the "App") is a private command-line tool that drake mooneyham runs on his own computer to upload and schedule videos on his own YouTube channel, Houseman Dubs. The App has no other users, no customers and no public interface. This policy explains what the App does with data.

The App uses YouTube API Services

The App uses YouTube API Services (the YouTube Data API v3) to work with the Houseman Dubs YouTube channel. By using the App you are also subject to the Google Privacy Policy: http://www.google.com/policies/privacy

What data the App accesses

When the channel owner signs in with Google and grants access, the App can access, for that one channel only:

  • the channel's ID and basic channel details (to confirm it's uploading to the right channel);
  • the videos the App uploads, their titles, descriptions, tags, privacy status, scheduled publish time and custom thumbnails;
  • the channel's playlists and playlist items (to add new uploads to the channel's own playlists).

The intended upload/channel-management OAuth scopes are https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube. Google's consent screen identifies the permissions actually requested before the owner grants access. The owner reviews this policy and the terms before authorizing the App. It does not access any other user's data, comments, subscribers' personal information, YouTube Analytics or Reporting data, or Google account data beyond what Google's sign-in returns to identify the channel.

How the data is used

Only to do what the channel owner asks: upload a finished video as private with a scheduled publish time, set its thumbnail, add it to a playlist, and read back the upload's status. The data is not used for advertising, profiling, analytics products or any other purpose.

What is stored, where, and for how long

  • OAuth token: stored only on the channel owner's computer (a local token file, never in a shared or public location) so the App can act without signing in on every run. The owner deletes it after access is revoked, within the period below; revocation is not a claim that local files delete themselves.
  • Upload records: the App may keep a local log of the video IDs it created and their scheduled times, on the same computer. Stored YouTube API data is refreshed (re-read from the API) or deleted within 30 days.
  • The App runs no server, keeps no database in the cloud, and sends YouTube API data to no third party.

Sharing

The App shares no data with anyone. Videos become public on YouTube only when the channel owner schedules or publishes them, under YouTube's own terms.

Revoking access and deleting data

  • You can revoke the App's access at any time from Google's security settings: https://security.google.com/settings/security/permissions (choose "Houseman Dubs Scheduler", then "Remove access").
  • After access is revoked, or on a deletion request sent to drake.mooneyham@gmail.com, the owner deletes all stored YouTube API data and the OAuth token within 7 days.
  • Videos already uploaded to YouTube stay on the channel until the channel owner deletes them in YouTube Studio.

Children

The App is not directed at children and is used only by the adult channel owner.

Changes

If this policy changes, the new version is posted on this page with a new effective date.

This public policy website

GitHub Pages hosts these public information pages. The pages contain no sign-in form, advertising, embedded media, or custom analytics/tracking scripts. The website does not receive the App's OAuth tokens or YouTube API data. GitHub may process standard website access information, such as IP addresses, under the GitHub Privacy Statement.
